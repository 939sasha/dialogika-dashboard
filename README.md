# Диалогика

Веб-дашборд анализа переписок сообщества ВКонтакте: воронка, потери, возражения, качество ответов, рекомендации ИИ и PDF-отчёт.

## Публикация через GitHub и Vercel

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое проекта.
2. Откройте Vercel, выберите **Add New → Project** и подключите этот репозиторий.
3. Нажмите **Deploy**. Vercel автоматически распознает Next.js и выдаст публичную ссылку.
4. Если ключ OpenAI не должен вводиться пользователем в интерфейсе, добавьте в настройках проекта Vercel переменную `OPENAI_API_KEY` и выполните повторное развёртывание.
5. При необходимости добавьте `OPENAI_MODEL`; значение по умолчанию — `gpt-5.6-luna`.

Токен сообщества ВК и ключ, введённый в интерфейсе, используются только в текущей вкладке и не записываются в GitHub.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`.

## Почему не GitHub Pages

GitHub Pages публикует только статические файлы. Дашборду нужны серверные маршруты для безопасных запросов к API ВКонтакте и OpenAI, поэтому GitHub используется для хранения кода, а Vercel — для запуска сайта.
